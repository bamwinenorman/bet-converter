# Bet Converter — SportyBet NG / Betway NG → BetPawa NG

## Setup (one time)
1. Make sure Node.js is installed: https://nodejs.org
2. Open terminal / command prompt
3. Navigate to this folder:
   ```
   cd bet-converter
   ```
4. Start the server:
   ```
   node server.js
   ```
5. You should see:
   ```
   Bet Converter Proxy · localhost:4000
   ```
6. Open `index.html` in your browser — the converter is ready.

## Keep running
The server must be running while you use the converter.
To stop it: press Ctrl+C in the terminal.

## No dependencies needed — pure Node.js, nothing to install.
